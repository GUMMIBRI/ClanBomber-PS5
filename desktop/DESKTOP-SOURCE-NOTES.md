# Desktop source and asset notes

The desktop port is based on the game source snapshot supplied with the
approved PS5 r32 build. Its five added mascot sprite sheets match that build
byte for byte. The original asset provenance is documented in
ASSET-PROVENANCE.md; that document's original upstream asset inventory does
not describe the five later mascot sheets.

Desktop source and build instructions are available in the repository's
desktop-ports-20261127 branch:
https://github.com/GUMMIBRI/ClanBomber-PS5/tree/desktop-ports-20261127

Linux binaries use the system SDL2, SDL2_image, SDL2_mixer and SDL2_ttf
libraries. Windows builds use the SDL project binaries and include their
notices and corresponding upstream source release links.
