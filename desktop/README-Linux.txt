Clan Bomber desktop build for x86-64 Linux

Extract the entire archive and run ./ClanBomber from the extracted directory.
This build requires SDL2, SDL2_image, SDL2_mixer and SDL2_ttf shared libraries.
On Ubuntu 22.04 install libsdl2-2.0-0, libsdl2-image-2.0-0,
libsdl2-mixer-2.0-0 and libsdl2-ttf-2.0-0. Other distributions may use
different package names. It was built on Ubuntu 22.04.

Player one uses the arrow keys to move and Enter to place bombs by default.
See the in-game player setup for additional controls. Optional custom character
files go in the characters directory alongside the executable.
Press P during a match to pause; use the arrow keys and Enter to navigate the
pause menu, or Backspace to go back.
